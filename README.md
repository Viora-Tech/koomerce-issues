# Koomerce issues

Report a bug or ask for a feature in [Koomerce](https://koomerce.app). Anyone can open an issue
here; the Koomerce team reads every one.

- **Something broken?** [Report a bug](../../issues/new?template=bug-report.yml)
- **Missing something?** [Request a feature](../../issues/new?template=feature-request.yml)
- **How do I…?** Check the [docs](https://docs.koomerce.app) first.
- **Is Koomerce down?** See [status.koomerce.app](https://status.koomerce.app).

## Before you post

This repository is **public**. Don't include:

- passwords, API keys, OTPs or payment details;
- customer names, emails, phone numbers or addresses;
- screenshots that show any of the above (blur them first).

Need to share something private, such as a store ID or an order? Email
[support@koomerce.app](mailto:support@koomerce.app) and mention your issue number.

**Security problems:** never report them here. Email
[support@koomerce.app](mailto:support@koomerce.app) with "Security" in the subject.
